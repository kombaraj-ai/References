	Upload all AWS Documentation PDFs

Create Knowledgebase
	Bedrock -> Knowledgebase -> "udemy_bedrock_KB"
		IAM Role - Create or Use existing one
		Choose the S3 bucket created "udemyknowledgebase"
		Select the Embedding Model
		Selct Vector Database -> Quick create new Vector Store (Amazon OpenSearch)
		"Sync" the Knowledgebase
	Test Knowledgebase
		Select Model -> Anthropic Claude

Create Lambda Function - "udemyknowledgebase-function"
	Set timeout 2 mins
	Provide "Bedrock_FullAccess" permission
	Copy & Paste the code - "lambda_function.py"
	Test the Lambda
	If any error with "boto3.client('bedrock-agent-runtime')"
		Upgrade boto3
			Create a lib folder by running the following command:
				LIB_DIR=boto3-mylayer/python
				mkdir -p $LIB_DIR
			Install the library to LIB_DIR by running the following command:
				pip3 install boto3 -t $LIB_DIR
			Zip all the dependencies to /tmp/boto3-mylayer.zip by running the following command:
				cd boto3-mylayer
				zip -r /tmp/boto3-mylayer.zip .
			Publish the layer by running the following command:
				aws lambda publish-layer-version --layer-name boto3-mylayer --zip-file fileb:///tmp/boto3-mylayer.zip
			The command returns the new layer's Amazon Resource Name (ARN), similar to the following one:

				arn:aws:lambda:region:$ACC_ID:layer:boto3-mylayer:1
			To attach this layer to your lambda execute the following:

				aws lambda update-function-configuration --function-name <name-of-your-lambda> --layers <layer ARN>
			To verify the boto version in your lambda you can simply add the following two print commands in your lambda:

				print(boto3.__version__)
				print(botocore.__version__)

Use Case 6 - Build a Retail Banking Agent using Amazon Bedrock Agents and Knowledge Bases -

                          Claude Sonnet + AWS Lambda + DynamoDB + Bedrock Agents + Knowledge Bases + OpenAPI Schema

Create DynamoDB Table - "customerAccountStatus"
	Partition Key - AccountID - Number
	AccountName
	AccountStatus
	Reason
	
	Create few records.
Create Lambda Function - "newBankAccountStatus" - lambda_function_retail_banking.py
	Timeout - 2 mins
	Provide "AmazonDynamoDBFullAccess"
Define OpenAPI Schema
	"newBankAccountStatus.yaml"
	Create S3 bucket "accountstatusopenapi" and upload the OpenAPI schema file
Create Bedrock Agent 
	Agent Name - "bankofchicago-agent"
	Description - This agent will help customer with status of their recently opened bank account
	Create or use existing role
	Select Model - Claude 3 Sonnet
	Instructions for the agent - You are a banking assistant in a retail bank. You are friendly and polite. You help customer queries by providing bank customers status on their new bank accounts.
	"Save & Exit"
	"Prepare"
	Edit the Agent
	Action Group - "action-group-demoagent"
		Action GRoup Type -> Select "Define with API schemas"
		Select the Lambda function "newBankAccountStatus"
		Action Group Schema -> Select the S3 bucket "accountstatusopenapi" where the API schema uploaded
	"Prepare"
	Provide access to the Agent to invoke Lambda Function
		Lambda Function -> Permission ->  Resource based policy statements -> Add Permission -> AWS Service -> Other (Bedrock not available as of now)
						Statement ID: bedrock-agent
						Principal: bedrock.amazonaws.com
						Source ARN: <ARN of the Agent>
						Action: lambdaInvokeFunction
						
	# AWS Documentation - Lambda Input event from Amazon Bedrock and Response back
						
	
	
Bedrock agent and Knowledgebase Integration
    Create S3 bucket "retailbankings3" and upload the PDF
	Bedrock -> Orchestration -> Knowledgebase -> "knowledgebase-retail"
		Select the S3 bucket
		Select Embedding Model
	Edit Bedrock agent -> Add Knowledgebase -> 
							Select the KB created
							KB instructions for the agent: Bedrock agent will utilize the knowledge base for any queries from the customer related to the reason for his AccountID status as pending
	"Save and Exit" -> "Prepare"
	Test the agent
